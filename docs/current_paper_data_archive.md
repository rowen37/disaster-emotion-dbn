# Current 流程论文数据归档

> 更新日期：2026-10-21。本文只归档当前指针 `models/current -> original_no_five` 所对应的 Stage 1–3 数据、模型与结果，不作历史版本比较。除特别说明外，区间均为 95% 可信区间（CrI）；`➕` 表示区间不含 0，`⭕` 表示区间包含 0。

## 0. 口径与结论边界

- Stage 1 的 `EMO_probs` 和 Stage 2 的 `behavior_prob` 均按现有模型原始输出使用，没有做事后概率校准。
- 情绪得分定义为 `E = P(angry) + P(fear) + P(sad)`；行为得分 `B = behavior_prob`。两者都是模型分数，不能直接解释为现实中情绪或行为发生的真实概率。
- Stage 2 的目标是“有害相关文本信号”，包括文本中明确出现的行为、主体身份、即时失控反应和直接有害后果；因此 Stage 3 的行为通道应表述为“有害相关文本信号”，而不是真实行为发生率。
- `theta1` 表示同一时空格内情绪得分与行为得分的同步耦合，`theta2` 表示前一 12 小时时间窗情绪得分与当前行为得分的滞后耦合。它们是条件关联参数，不构成“情绪引发行为”的因果证据。
- Current 核心 Stage 3 没有相邻网格空间滞后、发帖存在/计数联合模型、残差化动态、人口/GDP 分解或新增正则化。第 3.5 节另报告一组不改变 current 指针的“current 基础结构 + 人口/GDP”补充拟合，用于回答人口/GDP 主效应和调节效应问题。

| 帖子级判别 | Precision | 0.9585 ± 0.0382 |
| 帖子级判别 | Recall | 0.8714 ± 0.0373 |
| 帖子级判别 | F1 | 0.9125 ± 0.0332 |

帖子级 Accuracy、Precision、Recall 和 F1 以“CRF 是否解码出至少一个 span”作为模型阳性判定，与人工标注的 `has_behavior` 比较；PR-AUC 才以 presence 头输出的连续 `behavior_prob` 排序计算。严格边界指标要求预测 span 与人工 span 起止位置完全一致；字符重叠指标按预测与人工 span 覆盖字符的交集计算。`selection span F1` 是严格边界 F1 与字符重叠 F1 的算术平均，用于选择 checkpoint。

测试折平均每 200 条文本预测 101.2 ± 9.2 个 span；去除单字符片段后，15 次评估的单字符预测数均为 0。内层验证集的最佳 `selection span F1` 为 0.6006 ± 0.0562，它是 early stopping 的选择指标，不应与外层留出折表现混合解释。最终部署模型使用 seed 42、训练 6 个 epoch；6 也是 15 次交叉验证最佳 epoch 的中位数。

结果表明，模型对“文本是否含有害相关行为信号”的帖子级区分能力较强，而证据 span 的完整边界定位明显更难；字符重叠 F1 高于严格边界 F1，说明许多预测抓住了相关文字区域，但边界并未完全吻合。PR-AUC 衡量排序能力而非概率校准，因此这些结果不能证明 `behavior_prob` 已校准；Stage 3 仍将其解释为未经校准的连续有害相关文本信号，而不是真实行为发生概率。

完整网格均进入潜在状态过程；只有 `N>0` 的网格进入情绪和行为观测似然。情绪与行为共享同一个格子帖子数 `N`：情绪 logit-normal 观测标准差按 `1/sqrt(N)` 缩放，行为 Beta 观测精度按 `N` 放大。当前模型没有单独的 `N_e`、`N_b`，也没有显式建模“格子是否发帖”，因此若空格不是随机缺失，选择偏差仍可能存在。

### 3.2 核心模型口径

情绪观测在 logit 尺度用正态分布建模；行为观测在 `(0,1)` 上用 Beta 分布建模。核心动态为：

\[
e_{jkt}=\text{情绪基线}_{jkt}+\beta_e e_{jk,t-1}+\varepsilon^E_{jkt},
\]

\[
b_{jkt}=\text{行为基线}_{jkt}+\beta_b b_{jk,t-1}+\theta_1 e_{jkt}+\theta_2 e_{jk,t-1}+\varepsilon^B_{jkt}.
\]

两条基线均包含时间样条、距离样条、事件随机截距和灾害特征；台风额外使用“台风—路径点”嵌套随机截距，地震额外使用灾后阶跃项。拟合采用 mean-field ADVI，保留 1,000 个变分后验抽样；因此下文 CrI 是变分近似区间，不是 MCMC 区间。

### 3.5 GDP/人口主效应与调节效应

#### 3.5.1 补充模型定义

Current 核心模型本身没有人口/GDP 参数。为回答这一问题，在保持其他 current 结构、观测分布、网格、灾害特征、权重和推断设置不变的条件下，补充拟合了四个联合人口/GDP 模型；`models/current` 指针没有改变。

人口密度来自 `data/chn_pd_2020_1km.tif`，GDP 来自 `data/gdp2020.tif`。对每个事件的每个距离环提取栅格均值，负值按 NoData 处理，再分别做 `log1p` 和灾种内 z 标准化。人口与 GDP 同时进入同一模型：

\[
e_{jkt}=\text{current情绪结构}_{jkt}+\gamma^E_P P_{jk}+\gamma^E_G G_{jk},
\]

\[
\begin{aligned}
b_{jkt}={}&\text{current行为结构}_{jkt}+\gamma^B_P P_{jk}+\gamma^B_G G_{jk}\\
&+(\theta_1+\delta_{1P}P_{jk}+\delta_{1G}G_{jk})e_{jkt}\\
&+(\theta_2+\delta_{2P}P_{jk}+\delta_{2G}G_{jk})e_{jk,t-1}.
\end{aligned}
\]

其中主效应表示一个变量增加 1 个标准差、控制另一个变量后的潜在 logit 状态变化；B 主效应是含交互模型中 `e=0`、滞后 `e=0` 时的条件效应。调节系数表示该变量每增加 1 个标准差，`theta1` 或 `theta2` 改变多少。它们仍是观察性条件关联，不是因果效应。

## 4. Current 结果的主要限制

1. 情绪和行为输入都未校准，故所有曲线与参数作用于模型 score，而非真实发生概率。
2. 行为标签覆盖行为、主体身份、失控反应和后果，构念较宽；研究结论必须使用“有害相关文本信号”的表述。
3. 约 52.83% 的完整网格没有帖子，当前模型虽保留这些网格的潜在状态，却没有显式建模发帖选择过程。
4. 当前模型没有相邻空间传播项；距离样条描述空间轮廓，但不等于建模了网格之间的扩散。
5. 人口/GDP 只在第 3.5 节补充模型中加入，并非 current 核心参数；栅格关联仍可能混合城市化、平台使用率和空间选择机制，不能作因果解释。
6. ADVI 可能低估后验方差；台风情绪曲线较低的后验预测覆盖率与此风险一致。
7. 结果为观察性时空关联；未建立处理分配、可交换性或有效工具变量，不能做情绪导致行为的因果推断。
