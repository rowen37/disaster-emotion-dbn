# 参数与常数说明（项目第一要义）

**原则：任何参数和常数都必须可解释。** 本文逐条说明 `stage3-dbn/` 中每个常数、
先验、阈值的来源与理由。修改任何数值前先更新本文。

## 1. 数据分箱常数（config/hazards.R）

| 常数 | 值 | 来源 |
|---|---|---|
| TIME_MIN / TIME_MAX | -72 / +168 小时 | 论文 Methods 规定的采集窗口 |
| BIN_HOURS | 12 | 论文 Methods（20 个时间窗） |
| JUMP_START | 7 | **推导值**：(0-(-72))/12+1 = 7，即事件后首窗 [0,+12h)。旧代码 t≥8 为 off-by-one |
| K / ring_km / max_dist_km | 10环×5km×50km；台风 20环×10km×200km | 论文 Methods 与 S5 |
| df_dist / df_time | 6/8（台风空间 5） | 论文补充表 S5 的样条自由度设置 |

## 2. Stan 模型先验（stan/dbn_core.stan）

| 参数 | 先验 | 理由 |
|---|---|---|
| alpha_e/b | N(0, 1.5) | logit 基线的 ±2σ=±3 对应概率约 (0.05, 0.95)，覆盖合理基线范围而不偏袒 |
| psi_e/b（时间样条系数） | N(0, 2) | 允许 ±4 logit 的平滑时间起伏；再大会与 jump/截距混叠 |
| lambda_e/b（空间样条系数） | N(0, 2) | 同上，空间维度 |
| beta_e/b（自回归） | N(0, 0.8) | 弱平稳性约束：|β|<1 落在约 1.25σ 内；不预设持续性存在 |
| theta1/theta2（耦合） | N(0, 0.5) | 效应量预期远小于 1；对称先验不预设方向 |
| gamma_*_cov（协变量） | N(0, 1) | 协变量已标准化，先验即"1个SD的协变量差异 → 至多约1个logit" |
| gamma_mod | N(0, 1) | 同上 |
| delta_mod（调节） | N(0, 0.5) | 与 theta 同尺度：调节效应预期小于主效应 |
| jump_e/b | N(0, 1.5) | 阶跃与基线同尺度（±3 logit 封顶） |
| tau_w_e/b（路径点/事件级SD） | half-Cauchy(0, 1) | 层次SD的标准弱信息先验，重尾允许大异质性 |
| tau_v_e/b（台风级SD） | half-Cauchy(0, 1) | 同上 |
| sigma_obs_e / sigma_proc_e | half-Cauchy(0, 1) | 噪声尺度弱信息；二者分离避免观测噪声与过程动态混淆 |
| phi_b_beta（Beta精度基准） | half-Cauchy(0, 5) | 精度数量级可到数十；重尾防截断 |

**行为潜方差固定为 1.0**（`b_true ~ normal(mu_b, 1.0)`）：b 的尺度与 theta1/beta_b
不可同时识别（尺度混淆），固定方差 1 是标准识别性约束；论文 Methods 原文已有此声明。

## 3. 数值常数

| 常数 | 位置 | 理由 |
|---|---|---|
| 1e-6 | Stan：inv_logit 后的 clamp | Beta 分布支撑集为开区间 (0,1)，端点处似然无定义 |
| epsilon = 0.001 | R：logit 变换前 clamp | 概率 0/1 的 logit 为 ±∞；0.001 在 logit 尺度约 ±6.9，超出任何合理观测 |
| B_obs 缺失占位 0.5 / E_obs 缺失占位 0 | R：打包 | 占位值不进入似然（E_miss/B_miss=1 时观测项被跳过），取中性值仅为满足 Stan 数据类型 |
| n_posts 缺失下限 1 | R：打包 | 加权除法的分母保护；实际 N 缺失即格子无帖子，本就不进观测似然 |

## 4. 条件参数块（第一要义的实现）

`has_jump=0` 时 `jump_raw` 尺寸为 0（参数**不存在**于拟合中）；
`has_group=0` 时 `z_v_*_raw`、`tau_v_*_arr` 尺寸为 0。
draws 中仍会出现 transformed 的 `jump_e`/`tau_v_e`，此时恒为 0——那是确定性
常量而非自由参数（tests 的僵尸检查检查的是 `jump_raw` 等自由参数名）。

## 5. 拟合设置（config/hazards.R：fit_settings）

| 设置 | 值 | 理由 |
|---|---|---|
| algorithm | meanfield ADVI | 大 N（潜变量 2N 个）下 NUTS 代价高；已知会低估后验方差，重要结论需 NUTS 对照（待办） |
| iter | 30000 | 定稿上限；配合 tol=0.01 平台判据（20k 时多数拟合未达平台） |
| tol_rel_obj | 0.01 | ELBO 相对改善 <1% 的平台标准；收工时区分"因收敛停"与"撞迭代上限"并记录 |
| eta | 0.1 | 步长；0.1 在本模型上稳定（0.3 在地震上曾发散） |
| output_samples | 1000 | 后验汇总的常规抽样量 |
| seed | 123 | 可复现 |

## 6. 数据处理规则（R/typhoon_dedup.R）

| 规则 | 理由 |
|---|---|
| 帖子唯一键 = created_at + text + lon + lat | 微博无导出ID时的最严格组合键 |
| 同台风内归属空间最近路径点 | "最近接近"原则：帖子描述的是距该路径点最近的时刻的灾情 |
| 跨台风不去重 | 同城市先后受不同台风影响属于不同事件（时间窗不同） |
| 解析丢弃：前段/锚点/结构失败 | 逐行结构化解析无法定位列边界的行（源文件含未转义引号）；丢弃并计数，不静默 |
| 解析丢弃：raw_prob 为空的行 | 源数据本身缺失行为概率（NLP 未打分）；模型需要情绪+行为双通道成对观测 |
| 不在解析器里做 200km 过滤 | 距离过滤由 grid_one_event 的 max_dist_km 统一执行，单一职责 |

## 7. 已知的解释性事项

- **旧管道 fread 截断**：401-1.csv 有 41,918 条帖子，旧 RDS 只记录了 579 条
  （fread 在破损引号行静默截断）。旧台风结果建立在残缺输入上，本仓库的去重
  解析器为确定性行为，丢弃全部可解释（见 drop_report）。
- **phi_b_beta 的含义**：use_weights=1 时它是"每帖精度基准"，格子精度 = phi×n。
  与旧等权版本的 phi 不可直接比较。
